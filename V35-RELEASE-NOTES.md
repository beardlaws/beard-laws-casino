# Beard Laws Casino V35

V35 is built directly from the verified V32 Tribute Spectacle source. It preserves the V32 cabinets, portraits, reel/drop animation, bonus cinematics, roulette timing, exact pocket landing, and Beard Bank math.

Added in V35:

- Supabase email/password authentication and session restoration.
- Separate Guest and Cloud Player profiles.
- Debounced cloud wallet and Beard Bank progress saving.
- Sign in, create account, password reset, and sign out controls.
- $0.50, $1, $2, $3, and $5 wager controls in Neema's and Megh's slots.
- Wager-scaled awards and win tiers.
- Improved portrait-phone controls and layout.
- Beard Bank portrait view anchored to the top.

The `.env` file is intentionally excluded. Keep the connected `.env` already in your repository before running the production build.
