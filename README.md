# Project Gold Beard — Phase 1

Clean Vite + strict TypeScript + PixiJS architecture.

Included:

- `WalletManager.ts`
- `FeaturePipeline.ts`
- strict engine contracts
- money utilities
- initial Beard Bank typed state
- Vite base `/beard-laws-casino/`

The engine imports no PixiJS or DOM classes.

Run:

```bash
npm install
npm run typecheck
npm test
npm run build
```

Deploy the compiled `dist/` directory through GitHub Pages.
