# V72C — Megh's Cosmic Jam Showcase

## Character-first feature presentation
- Goat Stampede uses the guaranteed shared character layer above the cabinet.
- Each goat enters from the left, runs to the exact target tile, pauses to sniff, visibly chomps, creates crumbs, and exits right.
- Removed feature text overlays that previously pretended to be the character action.
- Strawberry tiles are preferred by the event and only selected positions are replaced.

## UFO abduction
- The UFO enters the cabinet, travels to each exact target position, locks on, and fires a narrow aligned beam.
- Target symbols rise, spin, shrink, and disappear into the craft one at a time.
- Replacements visibly drop into only the changed positions.
- The reel board remains readable with no full-screen purple fog.

## Foundation
- Built on V72A Reel Engine 3.0 and V72B Big Bad Barber.
- Uses FeatureDirector and CharacterLayer instead of fixed overlay tracks.
