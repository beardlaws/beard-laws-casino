# Beard Bank Slot Design Bible — Version 1.0

## Identity

Beard Bank is the flagship Beard Laws Casino slot. It is a premium gold-and-purple hold-and-grow machine centered on a fictional beard vault.

## Player Promise

“Grow the coins. Crack the vault.”

The player should understand the machine within ten seconds:

1. Spin the reels.
2. Normal symbol combinations can pay.
3. Beard Coins can appear anywhere.
4. Six or more Beard Coins trigger the vault feature.
5. During the feature, coin values can grow from stubble to legendary beard status.

## Cabinet

- Tall premium video cabinet
- Upper portrait screen with animated vault
- Lower 5×3 reel screen
- Gold metal frame
- Purple edge lighting
- Physical-looking illuminated SPIN button
- Bet selector and balance panel below reels
- Speaker grille and subtle cabinet reflections

## Base Game

- Five reels
- Three rows
- Fixed virtual reel strips
- Ten visible paylines in first production version
- Wild substitutes for normal line-pay symbols
- Coin symbols are feature symbols
- Independent outcome every spin

## Vault Hold Feature

Trigger:
- Six or more Beard Coins anywhere

Feature structure:
- Triggering coins lock in position
- Three-spin counter
- Any new coin resets the counter to three
- Coin values can be 1×, 2×, 3×, 5×, 10×, 15×, 25× or rarer premium values
- Comb symbols upgrade adjacent coins
- Oil symbols grow one selected coin through beard stages
- Filling all fifteen positions awards the Legendary Vault

## Growth Stages

1. Stubble
2. Five O’Clock Shadow
3. Short Beard
4. Full Beard
5. Mountain Beard
6. Legendary Beard

Growth is visual and mathematical: each stage increases the coin value according to a published feature table.

## Honest Presentation Rules

- No “BIG WIN” label below 10× bet
- No celebratory win sound when return is below the original bet
- Net-losing spins are displayed as losses
- Bonus teases occur only when produced by actual reel stops
- Reel stopping animations cannot change the selected outcome
- The player can open a Game Information screen showing rules and theoretical RTP
- Turbo mode changes animation speed only

## Math Targets

- Target RTP: 94%–95%
- Target base hit frequency: 25%–32%
- Target bonus frequency: 1 in 120–200 spins
- Volatility: medium-high
- Long losing stretches are possible
- Maximum win will be finite and published
- At least 10 million simulated spins before production lock
