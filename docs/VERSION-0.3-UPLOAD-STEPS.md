# Version 0.3 Upload Steps

1. Download and unzip `beard-laws-casino-v0.3.zip`.
2. Open the GitHub repository.
3. Choose **Add file → Upload files**.
4. Drag the contents of the unzipped folder into the upload area.
5. Allow GitHub to replace `index.html`, `styles.css`, `README.md`, and `app.js`.
6. Commit with: `Release playable casino floor v0.3`.
7. Wait for the green GitHub Pages deployment.
8. Hard refresh the website with Ctrl+F5.
9. Start a casino visit.
10. Confirm all four game cards open.
