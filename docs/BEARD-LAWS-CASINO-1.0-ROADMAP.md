# Beard Laws Casino 1.0 Roadmap

## North Star
Build the coolest personal family casino on the web: polished, funny, replayable, measurable, and unmistakably Beard Laws.

## Phase 1 — Project Beard Foundation
- [x] Shared reel engine
- [x] Shared feature timeline and character layer
- [x] Shared audio and cabinet effects
- [x] Canonical stylesheet entry point
- [x] Project manifest and cabinet identities
- [x] Repeatable audit and release scripts
- [ ] Retire legacy version CSS into named domain stylesheets
- [ ] Make every flagship cabinet use the same explicit game-state lifecycle
- [ ] Make actual cabinet math power every simulation report

## Definition of Done for a Milestone
1. Source changes are present in the package.
2. Typecheck and production build pass locally.
3. QA trigger exists for every new feature.
4. Math impact is measured.
5. GitHub Pages deploy fingerprint changes.
6. A human test checklist is completed before the next milestone.
